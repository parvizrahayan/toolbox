# جعبه‌ابزار

شامل publish.sh و صفحه‌ی وضعیت زنده‌ی پروژه‌ها.

## status.html

صفحه‌ای که وضعیت همه‌ی پروژه‌ها را از `status.json` می‌خواند و نشان می‌دهد.

آدرس: https://parvizrahayan.github.io/toolbox/status.html

## به‌روزرسانی وضعیت

فایل `status.json` را باز کن، `"done": false` را به `"done": true` تغییر بده وقتی کاری تمام شد، یا یک آیتم جدید اضافه کن. بعد:

```
bash publish.sh toolbox
```

(این کار معمولاً خودم بعد از هر جلسه‌ی کاری انجام می‌دهم — نیازی نیست خودت دستی انجامش بدهی.)
